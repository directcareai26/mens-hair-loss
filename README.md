# Mens Hair Loss — DirectCare AI

Single-page landing for DirectCare AI's men's hair regrowth program.

Built in the same style as [sexual-health-mocha.vercel.app](https://sexual-health-mocha.vercel.app/)
and `mens.directcare.ai`: dark video hero, four product cluster cards,
interactive ingredient explorer, science triad with SVG diagrams, 3-question
quiz, pricing, testimonials, FAQ, and a final CTA — all driving to the
Tellescope hair-loss intake form.

## Protocols featured

1. **Topical Male** — Finasteride + Minoxidil + Tretinoin
2. **Topical Men &amp; Women** — Minoxidil 5% + Fluocinolone 0.01% + Tretinoin 0.005%
3. **Topical Men &amp; Women** — Dutasteride 0.1% + Minoxidil 5% + Tretinoin 0.025%
4. **Topical + Oral Male** — Minoxidil 5% foam + Finasteride 1mg oral
5. **Oral Male Quad** — Minoxidil 1mg + Finasteride 1mg + Biotin 25mg + Nutrients 100mg
